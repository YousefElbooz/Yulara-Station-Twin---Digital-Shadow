# Twin API (step 8)

FastAPI بيشغل التوأم جواه في الخلفية (`backend/twin/runner.py`)، ويقرا الحالة من SQLite. الموقع مبيكلمش غير الـ API ده.

**التشغيل:** `.venv\Scripts\python -m uvicorn backend.api.app:app --port 8000`
- من الـ project folder، أو من `.claude/launch.json` باسم `twin-api`.

**التوثيق التفاعلي:** http://localhost:8000/docs

**الديمو:** `backend.api.demo_app:app` (أو `twin-api-demo` من `launch.json`) هو نفس الـ API، بس التوأم بيشتغل بالـ profile `runtime.demo` (speed mode من 4 أكتوبر 2025، ×90). التفاصيل في `docs/demo_script.md`.

**`TWIN_RUN=0`:** يشغل الـ API من غير ما يشغل التوأم، ويعرض آخر حالة اتحفظت.

| الطلب | بيرجّع إيه | الشاشة اللي هتستخدمه |
|---|---|---|
| `GET /api/health` | الـ API شغال؟ التوأم شغال ولا بيبدأ ولا فيه error؟ آخر خطوة | كل الشاشات (حالة الاتصال) |
| `GET /api/now` | آخر خطوة: المقاس، والمتوقع، والحالة، والطقس، وتوقعات الـ 8 موديلات، وطاقة النهارده لحد دلوقتي، والإنذارات المفتوحة | "المحطة دلوقتي" |
| `GET /api/series?hours=24` | سلسلة كل 5 دقايق لحد 7 أيام: المقاس، والفيزيا، وكل موديل، والطقس، والمصدر | "النهارده"، ومقارنة الموديلات |
| `GET /api/days?limit=60` | الأيام المقفولة: الطاقة، والـ PR، والتراب، وخسارة التقييد والانقطاع. الأيام اللي قبل بداية التوأم بتيجي من تاريخ الخطوة 5 (`source: history`) | "صحة المحطة" |
| `GET /api/alarms?open_only=false` | سجل الإنذارات، كل إنذار برسالته وتوصيته، وبالتوقيت المحلي | "الإنذارات" |
| `GET /api/health-history` | 2016–2026: تقسيم الطاقة كل سنة (حالة / تقييد / انقطاع)، والأحداث، وكل الأيام | "صحة المحطة" (التاريخ) |
| `GET /api/station` | مواصفات المحطة والمعايرة، والأرقام المحسوبة متعلّم عليها | "المحطة" |
| `GET /api/models` | الموديلات: النوع، ونتيجة الـ test وقت التدريب، ونتايج 2025 (كل النهار، واللحظات المش متقيدة) | "مقارنة الموديلات" |
| `GET /api/scene` | كل حاجة بيحتاجها المجسم: مكان الشمس، والرياح واتجاهها، والإشعاع على اللوح، وحرارة الخلايا وفقدها، ومؤشر التراب (ثقة منخفضة)، والقدرة والمقيد منها، وحرارة المعدات، والإنذارات، والـ layout | المجسم الـ 3D |
| `GET /api/twin/config` | التوأم شغال إزاي دلوقتي (live أو replay، والبداية، والسرعة)، والمدى المسموح، وتاريخ بداية توقعات الـ ML | الـ settings panel |
| `POST /api/twin/config` | يعيد تشغيل التوأم: `{"mode":"live"}` أو `{"mode":"replay","start":"2025-10-04T08:15","speed":90}` (بتوقيت Yulara، والسرعة من 1 لـ 600). بيرفض أي تاريخ برا 2016-04-01 → 2026-02-19 | الـ settings panel |
| `POST /api/whatif` | يوم حقيقي (2016–2026)، بتغييرات: حرارة ±، وتراب %، وميل، واتجاه، ومعامل حرارة، وسنين تقادم. بيرجّع المنحنى قبل وبعد والطاقة | "What-if" |

**مثال what-if:**
```json
POST /api/whatif
{"date": "2025-07-15", "temp_delta_c": 5, "soiling_pct": 5}
```
- **الناتج:** baseline 4,970 kWh، و scenario 4,622 kWh (−7%)، والمقاس 1,933 kWh.
- **في نفس اليوم بميل 25° بدل 15°:** 5,515 kWh (+11%، لأنه شتا والشمس واطية).

**حدود:**
- **`/api/series` و `/api/now`:** بيقروا من التوأم الشغال. التوأم بيبدأ من نص الليل بتوقيت Yulara كل ما الـ API يشتغل (`reset`)، فالسلسلة بتبدأ من النهارده.
- **مفيش إصدار من الـ API:** ده v0.1 للاستخدام المحلي، من غير authentication.

**وقت الـ restart:** لما الإعدادات بتتغير، التوأم بيفضّي جداوله ويبدأ من جديد. أي طلب في الثواني دي بيرجع 503 ("The twin is restarting")، والموقع بيستنى وبيعيد المحاولة لوحده.

**`/api/scene` → `weather.rain_mm_h` و `weather.cloud_cover`:** من ERA5 (`era5_precip_mm` و `era5_tcc`)، للساعة اللي فيها الخطوة. المطر هو كمية الساعة اللي بتخلص عند الـ timestamp. الموقع بيستخدمهم للمطر والسحاب في المجسم.

**Live weather:**
- `POST /api/twin/config {"mode":"weather"}` بيشغّل التوأم على الوقت الحقيقي، بطقس Open-Meteo لايف، ومن غير قدرة مقاسة.
- أو شغّل `backend.api.live_weather_app:app` (launch config اسمها `twin-api-live-weather`).
- `/api/health` بيرجّع `live_weather.fetched_utc` و `error`.
- `/api/scene` بيرجّع المطر والسحاب من Open-Meteo في الوضع ده.
